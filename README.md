# Md. Imran — Professional Portfolio

A deployable, responsive, premium-minimal static portfolio for a Performance Marketing Specialist.

## Included
- `index.html` — page structure/content
- `styles.css` — responsive UI
- `script.js` — mobile navigation + current year

## Before publishing
Replace the placeholders in `index.html`:
- `your-email@example.com`
- LinkedIn URL
- GitHub URL
- Any case-study links
- Any project/evidence details

Do not add invented results, certifications, testimonials, clients, or performance numbers.

## Deploy
This is a static site. It can be deployed on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any standard static host.

## Future upgrades
The content is currently hardcoded intentionally. Later it can be moved into JSON, a CMS, or a database without changing the overall design.
